# Femke's Keuken

Recepten-app voor Femke's iPhone: recepten met afvinkbare ingrediënten en stappen, een boodschappenlijst en eigen recepten toevoegen.

- **App:** https://maartenvp-app.github.io/Femke-keuken/
- **Recepten aanpassen:** `recepten.js`
- Installeren op iPhone: open de link in Safari → Deel → *Zet op beginscherm*.

Wat Femke zelf toevoegt of afvinkt, wordt alleen op haar telefoon bewaard.

## Klusjes (Maarten & Femke)

Klusjes in huis afvinken (wie deed het, hoe vaak), live gedeeld tussen beide telefoons.

- **Webapp / iPhone:** https://maartenvp-app.github.io/Femke-keuken/klusjes/ → Safari → Deel → *Zet op beginscherm*
- **Android-APK:** https://github.com/maartenvp-app/Femke-keuken/releases/latest/download/klusjes.apk
- Koppeling: `klusjes/config.js` (Firebase Realtime Database)
