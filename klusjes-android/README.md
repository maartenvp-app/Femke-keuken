# Klusjes – Android-app

Een simpele Android-app die de webapp `https://maartenvp-app.github.io/Femke-keuken/klusjes/` opent.
Wordt automatisch gebouwd door GitHub Actions (`.github/workflows/klusjes-apk.yml`) en gepubliceerd als release:

**Download:** https://github.com/maartenvp-app/Femke-keuken/releases/latest/download/klusjes.apk

De sleutel in `klusjes.keystore` is alleen voor deze thuis-app (zodat updates over de oude versie heen installeren).
